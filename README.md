# VALORANT Landing Page — React + Tailwind Activity

This project is based on the provided Tailwind CSS identification puzzle and is ready to run locally or deploy to Vercel.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deploy to Vercel

1. Upload/push this folder to a GitHub repository.
2. Sign in to Vercel.
3. Click **Add New > Project**.
4. Import the repository.
5. Vercel should detect **Vite** automatically.
6. Click **Deploy**.
